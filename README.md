# Lakshman Nair — Wii Portfolio

A Nintendo Wii–inspired personal portfolio built with Next.js.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

This is a standard Next.js App Router project. The easiest free host is **Vercel** — connect the GitHub repo and it will build on every push.
